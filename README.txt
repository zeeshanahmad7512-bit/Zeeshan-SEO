# Zeeshan Ahmad — SEO Portfolio

A responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Before publishing
1. Open `index.html` and replace `YOUR-PROJECT.pages.dev` with your actual Cloudflare Pages URL in:
   - canonical URL
   - Open Graph URL and image URL
   - JSON-LD `url`
2. Replace `YOUR-EMAIL@example.com` in the contact link with your real email address.
3. Update the same placeholder URL in `robots.txt` and `sitemap.xml`.
4. Review all service descriptions and only keep claims that accurately reflect your experience and services.
5. If you have a real professional portrait, you can add it later; the current design uses a CSS monogram and does not invent a headshot.

## Deploy to Cloudflare Pages
1. Upload the contents of this folder to a GitHub repository (the `index.html` file must be in the repository root).
2. In Cloudflare Dashboard, go to Workers & Pages → Create application → Pages → Connect to Git.
3. Select the repository.
4. Framework preset: None
5. Build command: leave blank
6. Build output directory: `.`
7. Deploy.

## SEO included
- Page title and meta description
- Canonical URL placeholder
- Open Graph metadata
- Person JSON-LD structured data
- `robots.txt`
- `sitemap.xml`
- Semantic headings, descriptive links and responsive layout

## Important
The portfolio does not claim specific client results, rankings, certifications or years of experience. Add verified details, case studies and contact information before publishing. Google Fonts are loaded from Google Fonts; the site itself remains static.
